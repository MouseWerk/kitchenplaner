# UI texts and glossary

The UI speaks German (default) and English. German addresses the user with "du". Every text lives
in the catalogs in `ui/src/locales/`; both languages stay complete.

## Rules

- „Computer“, not „Rechner“.
- Ellipsis directly after the word when a dialog follows: „Speichern unter…“, "Save as…".
- Units: lengths in millimetres (mm) in the UI and the files.
- Short, concrete labels; the same term for the same thing everywhere.
