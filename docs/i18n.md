# UI texts and glossary

The UI speaks German (default) and English. German addresses the user with "du". Every text lives
in the catalogs in `ui/src/locales/`; both languages stay complete.

## Rules

- „Computer“, not „Rechner“.
- Ellipsis directly after the word when a dialog follows: „Speichern unter…“, "Save as…".
- Units: lengths in millimetres (mm) in the UI and the files, always with the unit („1.500 mm“,
  „600 mm tief“), never metres.
- Short, concrete labels; the same term for the same thing everywhere. The same German text has the
  same English text and the other way round (checked; true homonyms are listed in the check).
- English is British: catalogue, centre, colour, litre; apostrophes ’, quotes “…”.
- Error messages say what failed and what to do next; a system message comes last, never alone.
- Direction words: horizontal/vertikal, not waagrecht/senkrecht.
- The introduction and the docs describe the keys themselves, not another program („wie in
  Blender“).

The translation check (`ui/src/lib/translations.test.ts`) enforces key parity, placeholders, quotes
and apostrophes, the terms below that have an „avoid“, the „du“ form and that every key is used.
