Kitchenplaner 0.2.2

A careful pass over the whole app: nothing you plan gets lost when saving or updating, the editor works with the keyboard alone, the window reads well at every size, and large kitchens stay quick.

## Improved

- Updating asks again before the restart if you changed something while the update was downloading, and keeps the download if you cancel.
- Closing, opening or starting a new project asks „Speichern“, „Nicht speichern“ or „Abbrechen“ instead of offering only to discard; a value you are still typing in a field counts as a change.
- Undoing back to the saved state shows the project as saved again.
- New units from the catalog land on a free spot along the walls, no longer inside a partition or in front of a door.
- The plan check knows heights: a hand wash basin under a wall shelf is no longer reported as overlapping. A turned unit that crosses the inner corner of an L-shaped room is reported.
- The editor works with the keyboard alone:
  - Tab switches between „Einrichten“ and „Raum“ only while the plan or the 3D view has the focus; elsewhere it moves on as usual.
  - N and Shift+N step through the units by position number; Shift+F10 or the menu key opens the context menu.
  - F6 jumps between the toolbar, the catalog, the views and the inspector.
  - The arrow keys move through the catalog and the toolbars; the catalog search has a clear button.
  - Screen readers hear what happens: placing, deleting, turning, mode changes and errors.
- The toolbar fits from 1000 px: buttons turn into icons with tooltips when space runs short, and the project name stays visible. Text that is cut off shows in full as a tooltip.
- Clearer contrast in the light and dark theme; selected rows show in bold. Windows contrast themes are supported.
- Large kitchens stay quick: moving 300 units at once in the overview is about ten times faster, the 3D view builds without freezing the window, and the plan with names stays quick with many units.
- Clearer words: „Ansicht“ only means an elevation, the layout with all views is called „Übersicht“, the cut depth reads „1.500 mm vor der Wand“, and error messages say what to do next.
- If something goes wrong while drawing the window, Kitchenplaner shows a message with „Speichern“ and „Fenster neu laden“ instead of an empty window.
- Updates are accepted only with a signature made for that exact version.

## Fixed

- After switching the language, clicking into a number field and out again no longer changes its value (for example the room height).
- Changes made while a project was being saved are no longer marked as saved.
- Escape during G or R no longer throws away a value you typed in the inspector meanwhile.
- Exports and the plan set no longer contain a move that is still in progress; a 3D picture right after opening a project shows every unit.
- Control characters in a text no longer break the SVG and PNG export; long project names and clients fit into the title block.
- Saving over a file that is open in another program (for example the equipment list in Excel) says so, instead of reporting missing permissions.
- The context menu takes the keyboard focus when it opens, so the arrow keys work after a right click.
- Switching between the layouts many times no longer leaves the 3D view or the catalog previews empty.

## Checklist for Windows (manual)

- Let 0.2.1 update itself with „Jetzt aktualisieren“: Kitchenplaner restarts as 0.2.2. Change something during the download: before the restart it asks whether to save.
- Open `Beispielkueche-Restaurant.kplan` from the release, change the room height, close the window: it asks „Speichern“, „Nicht speichern“ or „Abbrechen“; „Abbrechen“ keeps the window open.
- Switch to English under Darstellung, click into the room height and out again: the value stays 3,200 mm.
- Make the window 1000 px wide in „Einrichten“ and in „Raum“: every toolbar button is inside the window and nothing overlaps.
- Click the plan, press N a few times, then Shift+F10: units are selected in order and the context menu opens at the selection. Press F6: the focus moves to the next region.
- Select all units in the overview (A, then G) and move the mouse: the 3D view follows without stalling.
- Export the equipment list as CSV, open it in Excel, export it again to the same file: the message asks you to close the file in Excel.
- Turn on a Windows contrast theme: selected units and rows stay visible.
